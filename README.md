# Эмулятор командной оболочки ОС (Вариант №1)

## 1. Общее описание
Консольный эмулятор (CLI) UNIX-подобной командной строки. Поддерживает работу с
виртуальной файловой системой (VFS) в оперативной памяти без модификации данных
на диске, раскрытие переменных окружения ОС и выполнение стартовых скриптов.

## 2. Описание всех функций и настроек
### Параметры командной строки:
* `--vfs <путь>` — путь к физическому расположению директории VFS на диске.
* `--script <путь>` — путь к стартовому скрипту с командами эмулятора.

### Поддерживаемые команды:
* `ls [-l] [путь]` — вывод содержимого каталога (с `-l` выводит владельца и размер).
* `cd [путь]` — переход в указанный каталог VFS.
* `cat <файл...>` — вывод содержимого одного или нескольких файлов.
* `date` — вывод текущей системной даты и времени в формате UTC.
* `uname [-a]` — вывод сведений об операционной системе.
* `chown <владелец> <путь...>` — смена владельца файла или каталога в памяти VFS.
* `exit` — выход из эмулятора.
